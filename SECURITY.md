# Security Policy

## Supported Versions

Security fixes are provided for the latest released `0.x` version of
`unifilemanager/filament-file-manager`.

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub Security
Advisories:

https://github.com/UniFileManager/filament-file-manager/security/advisories/new

Do not open a public issue for suspected vulnerabilities.

When reporting, include:

- The affected package version.
- A clear description of the issue.
- Steps to reproduce, proof of concept, or relevant code paths.
- Any known mitigation or workaround.

I will acknowledge valid reports as soon as possible and coordinate a fix and
release before public disclosure.
